[![Analizador SEO Imagenes](https://img.shields.io/badge/TAVARDT-Image%20SEO-5b3cf5.svg)](https://tools.tavardt.com/mx/analizador-seo-imagenes/)

Revision de textos alt, compresion de recursos y velocidad de catalogo digital en Mexico.

Desarrollado y mantenido por la division de plataformas digitales y comercio electronico de **TAVARDT**.

***

## Capacidades de Auditoria de SEO para Imagenes

* **Inspeccion de Textos Alternativos Alt**: Control de presencia y calidad del atributo `alt` para mejorar visibilidad en Google Imagenes.
* **Adopcion de Formatos de Ultima Generacion**: Auditoria de formatos ligeros WebP y AVIF para reducir consumo de datos moviles.
* **Estabilidad Visual y Prevencion de CLS**: Verificacion de atributos explicitos `width` y `height`.
* **Carga Diferida (Lazy Loading)**: Comprobacion de directivas `loading="lazy"` para acelerar la presentacion visual.
* **Puntuacion de Salud Visual**: Indice cuantitativo de 0 a 100 con recomendaciones tecnicas priorizadas.

***

## Instalacion y Ejecucion

Requiere Python 3.8 o superior sin dependencias externas.

```bash
git clone https://github.com/TAVARDT-Mexico/image-seo-validator-mx.git
cd image-seo-validator-mx
python image_seo_validator.py https://empresa.com.mx
```

Para generar salida estructurada JSON:

```bash
python image_seo_validator.py https://empresa.com.mx -json
```
